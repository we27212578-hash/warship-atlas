# 全球戰艦史料室 Global Warship Atlas

點此開啟網站：https://github.com/we27212578-hash/warship-atlas

在情報室風格的 3D 地球上，瀏覽 1945 年以前各國大型艦艇的歷史。

- 拖曳轉動地球、滾輪縮放
- 滑鼠移到發光的國家上，會亮起該國的歷史領土範圍，中央浮現發光的國旗或徽記
- 點擊國家 → 艦種 → 艦級 → 單艦 → 地圖上的事件光點
- 任何一層都可以按 `ESC` 回到上一步

## 如何新增內容

這個專案的規則都寫在 [`AGENTS.md`](AGENTS.md)。請 AI 助手協助時，先讓它讀這份文件，然後直接說「幫我新增日本的長門級」之類的需求即可。
新增內容只需要改 `data/` 裡的 JSON 檔。

## 在自己的電腦上預覽

網站會用 `fetch` 讀取資料檔，所以不能直接點兩下開啟 `index.html`，需要啟動一個本機伺服器：

```
python3 -m http.server 8000
```

然後用瀏覽器開啟 `http://localhost:8000`。

檢查資料格式：

```
node scripts/validate.mjs
```

## 資料與圖片來源

- 文字內容依據各艦的維基百科條目整理，每艘船頁面下方列有參考資料。內容由 AI 協助撰寫，如發現錯誤歡迎指正。
- 照片於瀏覽時從維基百科／Wikimedia Commons 載入，僅取用自由授權的圖片，並附上來源連結。
- 國旗為自行繪製的簡化版本，依史實呈現各國當時使用的旗幟，僅供歷史教育用途，不代表認同任何政權或意識形態。
- 世界地圖：[world-atlas](https://github.com/topojson/world-atlas)（Natural Earth，公有領域）。地球繪製使用 [D3](https://d3js.org/)。地圖為現今國界；滑鼠移到國家上時顯示的歷史領土範圍是以現今國界拼湊的近似，並非精確的歷史疆界。
